# Pensamento Computacional (Unity) - Exercícios
 
Este repositório reúne os exercícios e projetos desenvolvidos durante as aulas de Pensamento Computacional utilizando a Unity.
 
## Objetivo
 
Disponibilizar os materiais trabalhados em sala para que os alunos possam acessar, revisar e praticar os conteúdos a qualquer momento.
 
## Exercícios
 
- Transform
- Boliche
- Space Clicker
 
## Como utilizar
 
1. Baixe o repositório.
2. Abra o projeto pelo Unity Hub.
