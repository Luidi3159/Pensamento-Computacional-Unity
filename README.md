# Sobre o Pensamento Computacional (Unity)

O curso foi criado para introduzir estudantes, calouros e demais interessados ao desenvolvimento de jogos digitais, abordando desde a utilização da interface da Unity até a criação de projetos completos. Durante as aulas, os participantes desenvolvem conhecimentos em programação, game design e criação de jogos.

## Sobre o Curso

Os principais conteúdos trabalhados são:

- Interface da Unity
- Conceitos de Game Design
- Lógica de Programação
- Programação Básica em C#
- Programação em C# aplicada à Unity
- Exercícios práticos para reforçar o aprendizado
- Desenvolvimento do projeto final **Labirinto 3D**
- Participação em uma **Game Jam**, onde os alunos recebem orientação para desenvolver seus próprios jogos

## Objetivo do Repositório

Disponibilizar os materiais utilizados durante as aulas para que os alunos possam acessar, revisar e praticar os conteúdos sempre que necessário.


## Exercícios Disponíveis

- Transform
- Boliche
- Space Clicker

## Como Utilizar

1. Clone ou baixe este repositório.
2. Abra o projeto utilizando o Unity Hub.
3. Utilize a versão recomendada da Unity.
4. Explore os exercícios e projetos disponíveis.
